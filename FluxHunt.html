The views

IR Report
Executive summary, attack narrative, timeline, affected assets, ATT&CK coverage, technical findings, IOCs and chain of custody. Export to PDF / HTML / Markdown.
Findings
Every detection, filterable by severity and category. Each links to its packets, hosts and ATT&CK technique.
Attack Map
Force-directed host graph: node colour = role (red = C2/exfil, orange = flagged), node size = traffic, red ring = high severity; edges are conversations (thicker = more bytes, arrow = main data direction). Use Fit/Freeze/Labels, click a legend role to hide it, or open the host table below. Alongside: the reconstructed kill-chain and a findings donut.
Overview
Timeline analysis (drag on the strip to select a window, then Filter packets to scope the Packets tab or Analyze window to re-run every detector on just that slice; Return to full capture from the banner), throughput, protocol hierarchy, expert-info / TCP health, top talkers and conversations. The packet filter also accepts after:/before: (seconds from start).
Hosts
Every host; click one for a consolidated host view (findings, sessions, enrichment).
Sessions
One row per connection with bytes, RTT, retransmissions and a Follow Stream button.
Indicators
External IPs, domains, carved files, certificates, credentials, JA3/JA4/JA3S and assets — exportable as STIX, MISP, CSV, Zeek, Suricata, YARA, Sigma, OpenIOC, CEF or ATT&CK Navigator.
Packets
Filterable packet list with full decode, hex, and .pcap / anonymised-.pcap / CSV export.

Reading findings honestly

Findings are heuristics demonstrated on synthetic traffic. Legitimate software (telemetry, updates, CDNs, backups) can resemble beaconing, exfiltration or fast-flux. Validate against known-good baselines and correlate with host logs before acting. IP region is the responsible RIR (not geolocation); ATT&CK IDs are a best-effort mapping, not attribution.
