FluxHunt

Hunting threats through traffic patterns.

FluxHunt is a single-file, fully offline tool for analysing packet captures. Drop in a pcap or pcapng, and it surfaces network anomalies, maps them to MITRE ATT&CK, carves out indicators, and assembles an incident-response report — entirely in your browser, with no backend and no network calls.

What it does

From raw packets to a report you can act on

A full capture-analysis pipeline — parsing, protocol decoding, heuristic detection, enrichment, and reporting — packed into one portable HTML file.

Deep protocol decoding

pcap/pcapng in both byte orders. ARP, IPv4/6, TCP/UDP/ICMP, DNS, HTTP, TLS (SNI, JA3/JA4/JA3S, X.509), SMB, Kerberos/NTLM, SNMP, DHCP, plus GRE/VXLAN/GTP-U decapsulation.

35+ detectors, ATT&CK-mapped

Beaconing (including jittered and rotating-destination), scans, tunnelling, DGA, lateral movement, exfiltration and more — each finding mapped to a MITRE ATT&CK technique.

Artifact & IOC extraction

Carved files with SHA-256, TLS certificates, captured credentials, JA3/JA4 fingerprints and an asset inventory — pulled straight from the wire.

Visual attack map

A force-directed topology, kill-chain strip and findings breakdown render the incident at a glance — with a colourblind-safe palette and PNG export.

IR-ready reporting

Executive summary, probable-attack narrative, timeline, affected assets, technical findings, IOC appendix and chain-of-custody — exportable to PDF, HTML or Markdown.

Exports everywhere

STIX 2.1, MISP, Suricata, YARA, Sigma, OpenIOC, CEF, Zeek logs, an ATT&CK Navigator layer, packet CSV, and a one-click case-package ZIP.

Privacy by construction

Your evidence never leaves the machine

FluxHunt is one HTML file with no dependencies and no server. It makes zero network requests, so sensitive or air-gapped captures stay exactly where you opened them.

Save FluxHunt.html, copy it to an isolated host, and open it in any modern browser — no install, no account, no connection.

  • Single file. Everything — parser, detectors, crypto, UI — inlined.
  • No backend. Parsing and analysis run client-side in JavaScript.
  • Self-contained crypto. MD5, SHA-1, SHA-256 and CRC-32 built in.
  • Open source. MIT-licensed — read, audit and extend every line.

Use responsibly. FluxHunt's detectors are heuristics and it analyses network evidence only. Its enrichment and ATT&CK mappings are approximate hints, not ground truth — validate findings against known-good baselines and correlate with host logs before acting on them.
